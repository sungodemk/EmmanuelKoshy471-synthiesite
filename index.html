Score file format

Scores are XML files with a .score extension. The format extends the one from Step 5. A score has one <score> root tag, which contains one or more <instrument> tags, each of which contains <note> tags.

<?xml version="1.0" encoding="utf-8"?>
<score bpm="100" beatspermeasure="4" vibratorate="6" vibratodepth="0.005"
       lesliespeed="0.8" ringfreq="220">
   <instrument instrument="Organ" main="0.4" ringmod="0.3">
      <note measure="1" beat="1" duration="2" note="C4" drawbars="88 8000 000"/>
   </instrument>
</score>

<score> attributes (global settings)

AttributeMeaningDefault
bpmTempo in beats per minute.120
beatspermeasureBeats in each measure.4
vibratorateOrgan vibrato speed in Hz.6
vibratodepthOrgan vibrato depth as a fraction of frequency (0.01 means ±1%). 0 turns vibrato off.0
lesliespeedLeslie speaker rotation speed in Hz (about 0.8 is slow, 6.5 is fast). 0 bypasses the Leslie.0
ringfreqFrequency in Hz of the ring modulator's sine wave.300

<instrument> attributes

AttributeMeaningDefault
instrumentWhich synthesizer plays the notes: Organ or ToneInstrument (the Step 5 sine tone).none
mainSend level to the dry output (send 0).1
ringmodSend level to the ring modulator.0

Send levels can also be placed on an individual <note> tag. A note's own value overrides the value on its instrument tag.

<note> attributes

AttributeMeaning
measureMeasure the note starts in, starting at 1.
beatBeat within the measure, starting at 1. Fractions are allowed (2.5 is halfway through beat 2).
durationLength of the note in beats. It is converted to seconds using the score's BPM.
notePitch name such as C4, F#3 or Bb4.
drawbarsOrgan only. Nine digits from 0 to 8, one per drawbar, in standard Hammond order. Spaces are ignored, so 88 8000 000 works. Defaults to 88 8000 000.

How the program works

The program is built on the Step 5 Synthie structure. CSynthesizer loads the score, sorts the notes by measure and beat, and generates audio one stereo frame at a time. On each frame it:

  1. Starts any notes whose measure and beat have arrived, creating one instrument object per note.
  2. Computes the shared vibrato value and passes it to every playing organ note.
  3. Asks each playing instrument for one frame and adds it to each effects send bus according to that instrument's send levels. Finished instruments are removed.
  4. Mixes the dry bus with the ring modulator's output, then runs the result through the Leslie speaker.
  5. Advances the time, beat and measure.

The output is streamed: each frame is written as soon as it is made, and the full piece is never held in memory.

Use of AI

An AI assistant (Claude) was used to help write the synthesizer code and to compose the music. The score was produced by a Python script, written with AI help, that generates the chord progression, bass line and melody as XML notes.
