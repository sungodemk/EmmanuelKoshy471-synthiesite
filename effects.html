Effects Component

Owner: Emmanuel Koshy

The effects component mixes audio from all instruments and sends it to the output. It includes ring modulation, with a separate send level for each instrument.

Each instrument has its own send levels.

Mixing and effects sends

The synthesizer keeps a bus for each send: send 0 is dry, and another feeds the ring modulator. Each instrument has its own levels, so parts can use different amounts of the effect.

Each frame, the synthesizer scales each instrument's output by its send level and adds it to the corresponding bus:

bus[send][channel] += instrument.Frame(channel) × instrument.Send(send)

The final output is

output = dry bus + RingMod(ring mod bus)

Set send levels on the <instrument> tag or override them on a <note>:

<instrument instrument="Organ" main="0.4" ringmod="0.3">

By default, an instrument goes to the dry output (main="1") and not the effect. Set main="0" to hear only the effect. In the selection, the middle melody goes to both buses; the rest is dry.

Ring modulation

Ring modulation multiplies the input by a sine wave:

out = in × sin(2π × ringfreq × t)

This creates frequencies at the sum and difference of the input and ringfreq, giving the sound a metallic, bell-like quality. Set ringfreq on the <score> tag; the selection uses 220 Hz.

The synthesizer uses one persistent CRingMod object, which keeps its sine wave continuous across samples.
