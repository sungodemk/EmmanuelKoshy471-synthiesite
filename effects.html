Effects Component

Owner: Emmanuel Koshy

The effects component receives audio from every playing instrument, mixes it, applies effects, and produces the final output. As a one-person team, the requirement is the basic level (the component passes audio). This implementation also includes one effect, ring modulation, with a controllable send for each instrument.

Each instrument also has its own controllable send levels (described below).

Mixing and effects sends

Instead of adding every instrument into a single output frame, the synthesizer keeps one bus per effects send. Send 0 is the dry (main) bus, and another send feeds the ring modulator. Each instrument carries its own send levels, so different parts of the piece can use different amounts of each effect.

Every frame, each instrument's output is multiplied by each of its send levels and added to that bus:

bus[send][channel] += instrument.Frame(channel) × instrument.Send(send)

After all instruments are summed, the output is

output = dry bus + RingMod(ring mod bus)

Send levels are read from the <instrument> tag and can be overridden on a single <note>:

<instrument instrument="Organ" main="0.4" ringmod="0.3">

With no send attributes, an instrument goes fully to the dry output (main="1") and nothing goes to the effect. Setting main="0" with a ring mod send gives the effect alone. In the full selection, the middle section's melody is sent to both the dry bus and the ring modulator, while the rest of the piece is dry.

Ring modulation

Ring modulation multiplies the input by a sine wave:

out = in × sin(2π × ringfreq × t)

This replaces each frequency in the input with two new ones, at the sum and the difference of the input frequency and ringfreq. Because those new frequencies are usually not harmonics of the note, the result has a metallic, bell-like quality. The modulator frequency is set with ringfreq on the <score> tag. The selection uses 220 Hz.

The ring modulator (CRingMod) is a single persistent object in the synthesizer, not one per note, and it runs every sample so its sine wave stays continuous.
